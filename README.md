# AI Workflows Lab

A curated collection of advanced mini-projects showcasing applied AI techniques — including **Prompt Engineering**, **RAG (Retrieval-Augmented Generation)**, and **Agentic Workflows** — using LangChain and LangGraph.

## Project Structure

Each folder in this repo is a standalone mini-project demonstrating one or more advanced AI techniques.

```
ai-workflows-lab/
├── rag_techniques/
│ └── simple_rag/
│   ├── main.py
│   ├── pipeline.py
│   ├── config.yaml
│   ├── prompts/
│   ├── data/
│   └── vectorstore/
├── prompt_engineering/
│ └── ...
├── agentic_workflows/
│ └── ...
└── requirements.txt
```
